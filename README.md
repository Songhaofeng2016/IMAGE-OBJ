# 图形铸造：本地图片转 3D 网格

一个完全在本机运行的轻量工具：选择图片、重建模式和 Ollama 视觉模型，生成可预览、可下载的 OBJ 网格。支持单物体重建和空间补全。应用不使用外部 API、CDN、遥测或云端服务，也不需要安装 Python 第三方包。

> 单张图片生成的是完整场景的粗略推测：应用会依据透视和常见结构补齐房间、家具及画外/遮挡部分，但这些不可见细节无法由单张照片验证，不是专业级测量或重建。

## 准备

1. 安装 Python 3.10 或更新版本。
2. 在本机安装并启动 [Ollama](https://ollama.com/)；运行期间应用只连接 `127.0.0.1:11434`。
3. 安装支持图像输入的模型，例如：

   ```powershell
   ollama pull qwen2.5vl:3b
   ```

   模型下载需要网络；下载完成后，应用运行和推理均可离线完成。也可使用已安装的 `llava`、`llama3.2-vision` 或其他 Ollama 视觉模型。

## 启动

双击 `run.bat`，或在此文件夹运行：

```powershell
python server.py
```

浏览器打开 <http://127.0.0.1:8765>。退出时在服务窗口按 `Ctrl+C`。

## 隐私与限制

- Web 服务仅绑定回环地址 `127.0.0.1`，不会监听局域网或公网网卡。
- Ollama 地址固定为 `127.0.0.1:11434`，服务端没有外网请求逻辑；网页也不加载远程资源。
- 图片只从浏览器发给同一台电脑上的本地服务，再交给本机 Ollama。
- 支持 PNG、JPG、WebP、GIF，图片最大 10 MB；导出格式为 OBJ。
- Ollama 中的模型需支持图像输入并能按 JSON Schema 返回网格；不同模型的网格质量会有差异。
